💳 Pagamento da OS (opcional)
Adicione quantas formas precisar. Ex.: PIX R$ 100,00 + Dinheiro R$ 50,00. O financeiro só é lançado quando houver pagamento registrado.
Na OS, informe o nome do cliente ou a placa. Ao digitar um cliente já cadastrado, o sistema localiza automaticamente a placa e os dados do veículo; se houver mais de um veículo, você escolhe qual usar. A placa é opcional para criar a OS. Adicione quantos serviços quiser. Para cada serviço, você pode alterar o valor cobrado somente nesta OS sem mudar o preço cadastrado no catálogo. Use Itens / Produtos para registrar materiais consumidos. O campo de pagamento é opcional no cadastro; para receber, use Receber / Concluir, onde é possível dividir o pagamento. Ao confirmar, o estoque e o financeiro são atualizados automaticamente.
