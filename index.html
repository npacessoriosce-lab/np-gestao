Na OS, informe o nome do cliente. A placa é opcional: se informar, os dados do veículo são puxados automaticamente do cadastro. Assim, você pode criar a OS somente com o cliente e adicionar a placa depois. Adicione quantos serviços quiser. 📦 Estoque

Controle simples e realista: cadastre o produto como você compra (galão, frasco, caixa, litro etc.). Use Entrada/Consumo quando precisar ajustar o estoque e informe o motivo. O sistema mantém o histórico das movimentações.

📤 Registrar saída / despesa

Use esta área para registrar despesas do mês, como salários, materiais, fornecedores e contas. Cada saída fica registrada no Financeiro e entra automaticamente no cálculo das despesas e do saldo.

📅 Contas fixas / recorrentes

Cadastre uma vez as contas que se repetem todo mês. Elas ficam salvas aqui até você excluir. Quando pagar, use Marcar como paga para lançar automaticamente no Financeiro. Se o valor mudar no mês, você pode alterar o valor antes de lançar.
