NP Gestão Automotiva — correção de dados na lista de OS

Esta versão mantém a numeração sequencial das OS e o Financeiro intactos.
Apenas a API da lista de OS foi ajustada para cruzar cada OS com o cadastro de veículos.

Quando a OS possui placa, usa a placa para localizar exatamente o veículo cadastrado.
Assim, a lista passa a mostrar o WhatsApp, marca, modelo, ano e demais dados já salvos no cadastro.
Quando a OS não possui placa, tenta localizar o veículo pelo nome do cliente.

O banco np_gestao.db não está incluído neste ZIP e não é recriado/substituído.
